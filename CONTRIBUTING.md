# Contributing

Use Python 3.11+, install `requirements.txt`, and keep development in `MOCK_MODE=true`. Run `make format-check lint typecheck test evaluate` before opening a change. Keep tests deterministic and offline. Do not add credentials, personal health information, copyrighted corpora, model weights, or local stores. Medical-safety language must remain within the educational boundary documented in the README. New retrieval behavior should include fixture-backed tests and honest evaluation notes.
